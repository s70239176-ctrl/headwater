Headwater is a standalone GenLayer Intelligent Contract that checks whether the sources behind a claim are independent, not just numerous. Validators fetch each source, a model labels stance and copying, and deterministic code counts origin clusters (same-domain and heavily overlapping text are merged without the model). Other contracts read is_corroborated / status. Verified with 109 Direct Mode tests, GenVM lint and SDK validation, and 5 passing live Studionet integration tests (one needed a re-run after a network timeout).
